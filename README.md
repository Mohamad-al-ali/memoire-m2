# M2 Thesis – HPC I/O Optimization

End-of-studies internship at **Inria Bordeaux**  
**Topic:** Optimization of I/O configurations for High-Performance Computing (HPC)

## Overview

This repository contains the work carried out as part of my M2 end-of-studies internship at Inria Bordeaux, focusing on I/O optimization for High-Performance Computing systems.

The objective is to optimize the configuration of the IO500 benchmark and investigate strategies for reducing the cost of experimental evaluations.

## Objectives

- Optimize the configuration of the IO500 benchmark on HPC systems.
- Compare different search strategies for parameter optimization.
- Investigate Bayesian optimization to reduce the number and cost of experiments.
- Evaluate the performance of different configurations.
